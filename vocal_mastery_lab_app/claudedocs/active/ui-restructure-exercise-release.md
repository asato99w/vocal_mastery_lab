# UI刷新設計書 - エクササイズ機能リリース版

## 概要

エクササイズ機能のリリースに合わせて、アプリ全体のUI構造を刷新する。
ホーム画面の3項目構成への変更と、画面向きに応じたナビゲーションUIの最適化を行う。

---

## 現状のUI構造

```
ホーム画面
├── 録音する → RecordingView（単発録音、プリセット選択可能）
├── 録音リスト → RecordingListView → AnalysisView
└── 設定 → SettingsView
```

---

## 新UI構造

### ホーム画面（3項目）

```
ホーム画面
├── エクササイズ → ExerciseView
├── 振り返り → ReviewView
└── 設定 → SettingsView
```

### 画面遷移図

```
ホーム画面（ボタン方式）
│
├── [🎤 エクササイズ] → ExerciseView
│   ├── エクササイズ一覧
│   │   └── 選択 → ExerciseExecutionView（実行フロー）
│   │       └── プリセット順に録音 → RecordingView
│   ├── クイックスタート → RecordingView（単発録音）
│   └── プリセット/エクササイズ管理
│
├── [📋 振り返り] → ReviewView
│   ├── セッション一覧（メイン表示）
│   │   └── セッション詳細 → SessionDetailView
│   │       └── 録音分析 → AnalysisView
│   └── 表示切り替え → すべての録音一覧
│
└── [⚙️ 設定] → SettingsView
```

## ナビゲーション設計

### 基本方針

- **ホーム画面**: ボタン方式（現状のデザイン踏襲）
- **縦画面**: 標準のNavigationStack（戻るボタン）
- **横画面**: 左サイドバー（展開式）で主要画面間を移動可能

### 画面別ナビゲーションUI

| 画面 | 縦画面 | 横画面 |
|------|--------|--------|
| ホーム | ボタン方式 | ボタン方式 |
| エクササイズ | 戻るボタン | サイドバー（展開式） |
| 振り返り | 戻るボタン | サイドバー（展開式） |
| 設定 | 戻るボタン | サイドバー（展開式） |
| 録音中 | 戻るボタン | サイドバー非表示（集中モード） |
| 分析 | 戻るボタン | サイドバー（展開式） |

### 横画面サイドバー仕様

```
通常時:
┌─────────────────────────────────────────┐
│ [≡]        （メインコンテンツ）           │
└─────────────────────────────────────────┘

サイドバー展開時（左端スワイプ or ボタン）:
┌────────────┬────────────────────────────┐
│ 🎤 エクササイズ │                        │
│ 📋 振り返り    │   （メインコンテンツ）    │
│ ⚙️ 設定       │                        │
└────────────┴────────────────────────────┘
```

- 普段は非表示でコンテンツ領域を最大化
- 左端スワイプまたはメニューボタンで展開
- 録音中は非表示（集中モード）

## 各画面の詳細設計

### 1. ホーム画面（HomeView）

現状のデザインを踏襲し、ボタンのラベルを変更。

```
┌───────────────────────────┐
│      Vocalis Studio       │
│        [ロゴ]             │
│                           │
│   [🎤 エクササイズ]        │
│   [📋 振り返り]           │
│   [⚙️ 設定]              │
│                           │
│   (プレミアムバナー)        │
└───────────────────────────┘
```

### 2. エクササイズ画面（ExerciseView）

エクササイズ一覧をメインに、クイックスタートをサブ機能として配置。

```
┌───────────────────────────┐
│ [<] エクササイズ           │
├───────────────────────────┤
│                           │
│ ┌───────────────────────┐ │
│ │ ▶ 朝のウォームアップ    │ │  ← エクササイズ一覧
│ │   3プリセット・約5分    │ │
│ └───────────────────────┘ │
│ ┌───────────────────────┐ │
│ │ ▶ 高音域トレーニング    │ │
│ │   2プリセット・約3分    │ │
│ └───────────────────────┘ │
│                           │
│ [+ 新規エクササイズ]       │
│                           │
├───────────────────────────┤
│ クイックスタート           │  ← サブ機能
│ [今すぐ録音 →]            │
└───────────────────────────┘
```

#### エクササイズ実行フロー

```
エクササイズ選択
    ↓
ExerciseExecutionView（実行画面）
    ├── 現在のプリセット表示
    ├── 進捗表示（1/3, 2/3, 3/3）
    └── [開始] → RecordingView
            ↓
        録音完了 → 次のプリセットへ
            ↓
        すべて完了 → セッション保存 → 完了画面
```

### 3. 振り返り画面（ReviewView）

セッション単位での表示をメインとする。

```
┌───────────────────────────┐
│ [<] 振り返り               │
├───────────────────────────┤
│ [セッション ▼]            │  ← 表示切り替え
├───────────────────────────┤
│                           │
│ ┌───────────────────────┐ │
│ │ 12/2 朝のウォームアップ  │ │
│ │ 3録音・5分30秒         │ │
│ │               [詳細 →] │ │
│ └───────────────────────┘ │
│                           │
│ ┌───────────────────────┐ │
│ │ 12/1 高音域トレーニング  │ │
│ │ 2録音・3分15秒         │ │
│ │               [詳細 →] │ │
│ └───────────────────────┘ │
│                           │
│ ┌───────────────────────┐ │
│ │ 12/1 クイック録音       │ │  ← 単発録音もセッションとして表示
│ │ 1録音・1分20秒         │ │
│ │               [詳細 →] │ │
│ └───────────────────────┘ │
│                           │
└───────────────────────────┘
```

#### 表示切り替え

- **セッション表示**: エクササイズセッション/クイック録音単位でグルーピング
- **すべての録音**: 従来の録音リスト（時系列）

### 4. 設定画面（SettingsView）

現状を踏襲。

## 新規エンティティ

### ExerciseSession（セッション）

```swift
public struct ExerciseSession: Identifiable, Codable, Equatable {
    public let id: UUID
    public let exerciseId: UUID?        // nil = クイック録音
    public let exerciseName: String?    // エクササイズ名（クイック録音時はnil）
    public let recordings: [RecordingId]
    public let startedAt: Date
    public let completedAt: Date?
}
```

- `exerciseId`がnilの場合はクイック録音（単発）
- すべての録音はセッションに紐づく
